# Révisions ESG M1

Cahier de révision interactif (fiches de cours, QCB/QCM, flashcards, glossaire, examen blanc) servi via Streamlit.

- `static/index.html` : l'application (HTML/JS autonome)
- `app.py` : point d'entrée Streamlit qui affiche l'application

## Lancer en local

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Déployer

Sur [share.streamlit.io](https://share.streamlit.io) : **Create app** → repo `Samadkod/revisions-esg-m1`, branche `main`, fichier `app.py`.
